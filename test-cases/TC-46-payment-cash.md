# TC-46: Pembayaran - Admin melakukan pembayaran dengan metode tunai

## Deskripsi
Admin melakukan pembayaran dengan metode tunai. (Sesuai referensi SBA_032).

## Pre-conditions
- Halaman proses pembayaran terbuka dan invoice belum lunas.

## Skenario: Admin melakukan pembayaran dengan metode tunai

Langkah-langkah:

1. Pilih metode tunai
2. Isi jumlah pembayaran
3. Klik selesaikan pembayaran

Test Data:

- Metode: tunai, jumlah pembayaran sesuaikan dengan tagihan.

Expected Result:

- Pembayaran tunai berhasil diselesaikan.

Actual Result:

- Pembayaran dengan metode tunai berhasil.

**Status:** PASS
