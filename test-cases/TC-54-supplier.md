# TC-54: Admin ingin membuat data supplier

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin membuat data supplier.

## Pre-conditions

- Admin sudah berhasil Login

## Test Data

- Input Data:
- Nama
- Alamat
- Telp
- Kontak
- NPWP
- No Rekening
- Nama bank
- Keterangan
- Due Date
- PPN

## Skenario: Admin ingin membuat data supplier

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
4. Memilih halaman stok menu dan pembelian di sidebar
5. Memilih sub-menu Supplier

Expected Result:

- Form Buat Supplier terbuka
- Menampilkan data yang sudah di inputkan di tabel

Actual Result:
Form Buat Supplier terbuka
Menampilkan data yang sudah di inputkan di tabel
Status: PASS
