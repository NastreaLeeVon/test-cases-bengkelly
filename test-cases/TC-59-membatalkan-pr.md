# TC-59: Admin ingin membatalkan data PR Pembelian

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin membatalkan data PR Pembelian.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.

## Skenario: Admin ingin membatalkan data PR Pembelian

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
4. Memilih halaman stok menu dan pembelian di sidebar
5. memilih sub-menu PR

Expected Result:

- Menampilkan popup message konfirmasi "Apa anda yakin ingin membatalkan PR"
- Menampilkan popup message konfirmasi "Dibatalkan"
- Data berhasil dibatalkan

Actual Result:
Menampilkan popup message konfirmasi "Apa anda yakin ingin membatalkan PR"
Menampilkan popup message konfirmasi "Dibatalkan"
Data berhasil dibatalkan
Status: PASS
