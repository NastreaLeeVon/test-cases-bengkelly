# TC-88: Admin ingin melihat detail penyesuaian stok dan menyetujui penyesuaian stok

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin melihat detail penyesuaian stok dan menyetujui penyesuaian stok.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.

## Skenario: Admin ingin melihat detail penyesuaian stok dan menyetujui penyesuaian stok

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
4. Memilih halaman stok menu dan pembelian di sidebar
5. Memilih sub-menu Penyesuaian Stok

Expected Result:

- Menampilkan detail dari penyesuaian stok yang dilakukan
- Menampilkan tombol print untuk bukti kuitansi penyesuaian stok
- Menampilkan button setujui penyesuaian
- Menampilkan push notification berhasil

Actual Result:
Menampilkan detail dari transfer stok yang dilakukan
Menampilkan tombol print untuk bukti kuitansi transfer stok
Menampilkan button kirim transfer
Menampilkan push notification berhasil
Status: PASS
