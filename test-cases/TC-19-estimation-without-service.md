# TC-19: Estimasi - Membuat estimasi tanpa jasa layanan individu

## Deskripsi
Membuat estimasi tanpa jasa layanan individu. (Sesuai referensi SBA_005).

## Pre-conditions
- Tidak ada kebutuhan jasa tambahan diluar paket.

## Skenario: Membuat estimasi tanpa jasa layanan individu

Langkah-langkah:

1. Buka estimasi

Test Data:

- Tanpa jasa individu.

Expected Result:

- Estimasi dapat dibuat tanpa jasa layanan indicidu jika tidak ada kebutuhan tambahan.

Actual Result:

- Estimasi berhasil tanpa dibuat jasa indivdu.

**Status:** PASS
