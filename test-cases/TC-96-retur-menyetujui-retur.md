# TC-96: Admin ingin melihat detail retur pembelian dan menyetujui retur

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin melihat detail retur pembelian dan menyetujui retur.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.

## Skenario: Admin ingin melihat detail retur pembelian dan menyetujui retur

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
