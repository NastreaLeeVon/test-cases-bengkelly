# TC-48: Planning - Admin memeriksa fungsi dan informasi pada modul planning

## Deskripsi
Admin memeriksa fungsi dan informasi pada modul planning. (Sesuai referensi SBA_034).

## Pre-conditions
- Admin sudah login dan modul planning dapat diakses.

## Skenario: Admin memeriksa fungsi dan informasi pada modul planning

Langkah-langkah:

1. Buka menu planning
2. Periksa planning mekanik
3. Periksa service reminder
4. Periksa planning inventory dan kapasitas bengkel

Test Data:

- Data planning tersedia.

Expected Result:

- Halaman planning dapat dibuka dan informasi yang tersedia tampil sesuai kondisi sistem.

Actual Result:

- Modul planning berhasil diakses dan informasi planning dapat ditampilkan.

**Status:** PASS
