# TC-42: PKB - Admin mengubah status pekerjaan menjadi selesai

## Deskripsi
Admin mengubah status pekerjaan menjadi selesai. (Sesuai referensi SBA_028).

## Pre-conditions
- PKB berstatus dikerjakan dan mekanik sudah ditugaskan.

## Skenario: Admin mengubah status pekerjaan menjadi selesai

Langkah-langkah:

1. Buka detail PKB
2. Ubah status pekerjaan menjadi selesai
3. Periksa status akhir

Test Data:

- Status awal: dikerjakan.

Expected Result:

- Status pekerjaan berubah menjadi selesai.

Actual Result:

- Status pekerjaan berhasil menjadi selesai.

**Status:** PASS
