# TC-29: Estimasi - Admin mencetak dokumen estimasi

## Deskripsi
Admin mencetak dokumen estimasi. (Sesuai referensi SBA_015).

## Pre-conditions
- Estimasi sudah tersedia.

## Skenario: Admin mencetak dokumen estimasi

Langkah-langkah:

1. Buka detail estimasi
2. Klik print

Test Data:

- Data estimasi tersedia.

Expected Result:

- Dokumen estimasi berhasil dibuka untuk proses print/cetak.

Actual Result:

- Estimasi berhasil di print.

**Status:** PASS
