# TC-36: PKB - Admin Membatalkan pembuatan PKB

## Deskripsi
Admin Membatalkan pembuatan PKB. (Sesuai referensi SBA_022).

## Pre-conditions
- Admin berada pada form buat PKB baru dan data belum disimpan.

## Skenario: Admin Membatalkan pembuatan PKB

Langkah-langkah:

1. Isi data PKB
2. Klik button batal
3. Periksa halaman setelah pembatalan

Test Data:

- Data PKB belum disimpan.

Expected Result:

- Proses pembuatan PKB dibatalkan dan tidak tersimpan sebagai PKB baru.

Actual Result:

- Pembuatan PKB berhasil dibatalkan.

**Status:** PASS
