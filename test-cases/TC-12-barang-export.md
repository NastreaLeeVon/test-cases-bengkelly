# TC-12: Barang/Sparepart - Export Data

## Deskripsi
Test case manual untuk memvalidasi bahwa Admin dapat mengeksport data barang/sparepart ke dalam bentuk XLSX. (Sesuai referensi TMA_0012).

## Pre-conditions
- Aplikasi dapat diakses dengan normal di staging.
- Admin sudah berhasil login.
## Skenario: Admin ingin mengeksport data barang/sparepart dalam aplikasi ke luar
Langkah-langkah:
1. Admin membuka halaman login.
2. Admin berhasil login.
3. Admin menavigasi ke menu Master Data > Barang/Sparepart.
4. Klik tombol Export.

Expected Result:
- Bisa mengkesport data barang/sparepart menjadi bentuk XLSX.
- File Excel berhasil di-download ke lokal komputer.
