# TC-62: Admin ingin membuat data PO Pembelian baru

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin membuat data PO Pembelian baru.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.
