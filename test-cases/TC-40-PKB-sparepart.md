# TC-40: PKB - Admin mengambil sparepart untuk pengerjaan PKB

## Deskripsi
Admin mengambil sparepart untuk pengerjaan PKB. (Sesuai referensi SBA_026).

## Pre-conditions
- PKB memiliki kebutuhan sparepart dan stok tersedia di gudang.

## Skenario: Admin mengambil sparepart untuk pengerjaan PKB

Langkah-langkah:

1. Buka PKB
2. Klik ambil part
3. Pilih sparepart dan quantity
4. Konfirmasi pengambilan

Test Data:

- Sparepart tersedia di gudang.

Expected Result:

- Sparepart berhasil diambil sesuai quantity dan tercatat pada PKB.

Actual Result:

- Part berhasil diambil dari gudang.

**Status:** PASS
