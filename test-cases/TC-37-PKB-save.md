# TC-37: PKB - Admin membuat dan menyimpan PKB

## Deskripsi
Admin membuat dan menyimpan PKB. (Sesuai referensi SBA_023).

## Pre-conditions
- Data customer, kendaraan, service, dan kebutuhan PKB sudah lengkap.

## Skenario: Admin membuat dan menyimpan PKB

Langkah-langkah:

1. Lengkapi data PKB
2. Klik buat PKB sekarang
3. Periksa detail/status PKB

Test Data:

- Data PKB valid.

Expected Result:

- PKB berhasil dibuat, disimpan, dan detail PKB dapat ditampilkan.

Actual Result:

- PKB berhasil dibuat dan tersimpan dengan status menunggu.

**Status:** PASS
