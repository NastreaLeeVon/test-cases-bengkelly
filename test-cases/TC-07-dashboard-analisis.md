# TC-07: Dashboard - Tab Analisis & Trend

## Deskripsi
Test case manual untuk memvalidasi bahwa Admin dapat melihat data table analisis dan trend di dashboard. (Sesuai referensi TMA_0007).

## Pre-conditions
- Aplikasi dapat diakses dengan normal di staging.
- Admin sudah berhasil login.
## Skenario: Admin ingin melihat data table di tab analisis dan trend.
Langkah-langkah:
1. Admin membuka halaman login.
2. Admin berhasil login.
3. Admin melihat tampilan dashboard utama bagian analisis.

Expected Result:
- Menampilkan data omset 7 hari terakhir.
- Menampilkan data dan status PKB.
