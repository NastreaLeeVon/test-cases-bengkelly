# TC-39: PKB - Admin mengedit data PKB

## Deskripsi
Admin mengedit data PKB. (Sesuai referensi SBA_025).

## Pre-conditions
- Data PKB sudah tersedia dan dapat diedit.

## Skenario: Admin mengedit data PKB

Langkah-langkah:

1. Buka detail PKB
2. Klik edit
3. Ubah data PKB
4. Simpan perubahan dan periksa

Test Data:

- Data PKB yang akan diubah.

Expected Result:

- Perubahan data PKB berhasil disimpan dan tampil pada detaiil PKB.

Actual Result:

- Data PKB berhasil diedit dan perubahan tersimpan.

**Status:** PASS
