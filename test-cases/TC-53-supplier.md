# TC-53: Admin ingin melihat list data supplier

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin melihat list data supplier.

## Pre-conditions

- Admin sudah berhasil Login

## Test Data

- Tidak ada data.

## Skenario: Admin ingin melihat list data supplier

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
