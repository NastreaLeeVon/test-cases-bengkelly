# TC-41: PKB - Admin menugaskan mekanik pada pekerjaan service

## Deskripsi
Admin menugaskan mekanik pada pekerjaan service. (Sesuai referensi SBA_027).

## Pre-conditions
- PKB sudah dibuat dan pekerjaan siap dikerjakan.

## Skenario: Admin menugaskan mekanik pada pekerjaan service

Langkah-langkah:

1. Buka detail PKB
2. Klik tugaskan
3. Pilih mekanik
4. Simpan perubahan

Test Data:

- Memperkerjakan mekanik.

Expected Result:

- Mekanik berhasil ditugaskan pada pekerjaan service.

Actual Result:

- Mekanik berhasil ditugaskan dan status pekerjaan berubah menjadi dikerjakan.

**Status:** PASS
