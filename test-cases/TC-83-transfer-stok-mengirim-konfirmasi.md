# TC-83: Admin ingin melihat detail transfer stok dan mengirim konfirmasi transfer stok

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin melihat detail transfer stok dan mengirim konfirmasi transfer stok.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.

## Skenario: Admin ingin melihat detail transfer stok dan mengirim konfirmasi transfer stok

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
4. Memilih halaman stok menu dan pembelian di sidebar
5. Memilih sub-menu Transfer Stok

Expected Result:

- Menampilkan detail dari transfer stok yang dilakukan
- Menampilkan tombol print untuk bukti kuitansi transfer stok
- Menampilkan button kirim transfer
- Menampilkan popup validasi pengiriman transfer stok gudang

Actual Result:
Menampilkan detail dari transfer stok yang dilakukan
Menampilkan tombol print untuk bukti kuitansi transfer stok
Menampilkan button kirim transfer
Menampilkan popup validasi pengiriman transfer stok gudang
