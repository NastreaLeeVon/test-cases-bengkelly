# TC-17: Booking - Admin mengonfirmasi booking

## Deskripsi
Admin mengonfirmasi booking. (Sesuai referensi SBA_003).

## Pre-conditions
- Booking berstatus pending

## Skenario: Admin mengonfirmasi booking

Langkah-langkah:

1. Buka detail booking

Test Data:

- Booking pending

Expected Result:

- Status berubah menjadi CONFIRMED dan tombol buat estimasi tersedia.

Actual Result:

- Status berubah menjadi CONFIRMED dan tombol buat estimasi tampil

**Status:** PASS
