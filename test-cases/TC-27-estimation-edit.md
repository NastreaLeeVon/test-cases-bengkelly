# TC-27: Estimasi - Admin mengedit data estimasi

## Deskripsi
Admin mengedit data estimasi. (Sesuai referensi SBA_013).

## Pre-conditions
- Data estimasi sudah berhasil dibuat dan tersedia pada detail estimasi.

## Skenario: Admin mengedit data estimasi

Langkah-langkah:

1. Buka detail estimasi
2. Klik tombol edit
3. Ubah data estimasi
4. Simpan perubahan

Test Data:

- Data estimasi yang akan diubah

Expected Result:

- Data estimasi berhasil diperbarui dan perubahan tampil pada detail estimasi.

Actual Result:

- Data estimasi berhasil diedit dan perubahan berhasil diperbarui

**Status:** PASS
