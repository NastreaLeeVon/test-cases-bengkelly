# TC-93: Admin ingin melakukan print data file Stock Opname

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin melakukan print data file Stock Opname.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.

## Skenario: Admin ingin melakukan print data file Stock Opname

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
4. Memilih halaman stok menu dan pembelian di sidebar
5. Memilih sub-menu Stok Opname

Expected Result:

- Menampilkan tabel Keterangan Stock Opname Rutin, dgn kolom:
- Kode
- Nama Barang
- Stok
- Fisik
- Adjust
- Lokasi
- Harga Beli
- Harga Jual
- Menampilkan button Print (biru)
- Menampilkan button Batal (Merah)
- Menampilkan halaman print
- Menampilkan data lengkap stock opname

Actual Result:
Menampilkan tabel Keterangan Stock Opname Rutin, dgn kolom:
  - Kode
  - Nama Barang
  - Stok
  - Fisik
  - Adjust
  - Lokasi
  - Harga Beli
  - Harga Jual
Menampilkan button Print (biru)
Menampilkan button Batal (Merah)
Menampilkan halaman print
Menampilkan data lengkap stock opname
Status: PASS
