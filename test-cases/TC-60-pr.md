# TC-60: Admin ingin membuat data PR Pembelian baru

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin membuat data PR Pembelian baru.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Input Data:
- Qty

## Skenario: Admin ingin membuat data PR Pembelian baru

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
4. Memilih halaman stok menu dan pembelian di sidebar
5. Memilih sub-menu PR

- Menampilkan form informasi PR:
- Tanggal request
- Tanggal dibutuhkan
- Priority
- Gudang tujuan
- Tujuan/keperluan
- Catatan

- Button batalkan
