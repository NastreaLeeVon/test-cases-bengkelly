# TC-57: Admin ingin melihat data PR Pembelian

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin melihat data PR Pembelian.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.

## Skenario: Admin ingin melihat data PR Pembelian

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
4. Memilih halaman stok menu dan pembelian di sidebar
5. memilih sub-menu PR

Expected Result:

- Menampilkan ringkasan data supplier dengan format:
- Total PR
- Pending
- Approve
- Done
- List supplier dengan format:
- nomor
- requester
- tujuan/keperluan
- prioritas
- status
- aksi

Actual Result:
Menampilkan ringkasan data supplier dengan format:
- Total PR
- Pending
- Approve
- Done
 List supplier dengan format:
- nomor
- requester
- tujuan/keperluan
