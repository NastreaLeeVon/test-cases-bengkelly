# TC-30: PKB - Admin mengisi data customer, kendaraan, tipe service, dan prioritas pada PKB

## Deskripsi
Admin mengisi data customer, kendaraan, tipe service, dan prioritas pada PKB. (Sesuai referensi SBA_016).

## Pre-conditions
- Admin berada pada halaman buat PKB baru dan data customer serta kendaraan tersedia.

## Skenario: Admin mengisi data customer, kendaraan, tipe service, dan prioritas pada PKB

Langkah-langkah:

1. Buka halaman buat PKB
2. Pilih customer dan kendaraan
3. Pilih tipe service
4. Periksa prioritas yang digunakan

Test Data:

- Customer, kendaraan, tipe service dan prioritas
- terdaftar.

Expected Result:

- Data customer, kendaraan, tipe service, dan prioritas tampil sesuai pilihan.

Actual Result:

- Data customer, kendaraan, tipe servicce, dan prioritas berhasil.

**Status:** PASS
