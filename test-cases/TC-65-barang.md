# TC-65: Admin ingin melihat data Penerimaan Barang dan membuat Penerimaan Barang

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin melihat data Penerimaan Barang dan membuat Penerimaan Barang.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.

## Skenario: Admin ingin melihat data Penerimaan Barang dan membuat Penerimaan Barang

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
4. Memilih halaman stok menu dan pembelian di sidebar
5. Memilih sub-menu Penerimaan Barang

Expected Result:

- Menampilkan card ringkasan dan list dari Penerimaan barang
- Menampilkan tombol tambah terima barang
- Menampilkan searchbar dan filter button
- Dapat mengisi form pembuatan Penerimaan Barang baru dengan format:
- Pilih PO
- Daftar Barang
- Informasi Penerimaan
- Button penerimaan dan batal

Actual Result:
Menampilkan card ringkasan dan list dari Penerimaan barang
Menampilkan tombol tambah terima barang
Menampilkan searchbar dan filter button
Dapat mengisi form pembuatan Penerimaan Barang baru dengan format:
- Pilih PO
- Daftar Barang
- Informasi Penerimaan
- Button penerimaan dan batal
Status: PASS
