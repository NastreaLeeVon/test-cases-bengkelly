# TC-26: Estimasi - Admin melakukan reset pada form estimasi

## Deskripsi
Admin melakukan reset pada form estimasi. (Sesuai referensi SBA_012).

## Pre-conditions
- Admin berada pada halaman tambah estimasi dan sudah mengisi data estimasi.

## Skenario: Admin melakukan reset pada form estimasi

Langkah-langkah:

1. Isi data pada form estimasi
2. Klik tombol reset form
3. Periksa kembali seluruh field pada form.

Test Data:

- Data estimasi yang sudah diisi

Expected Result:

- Seluruh isian form estimasi kembali ke kondisi awal/kosong

Actual Result:

- Setelah tombol reset form diklik, pengisian form berhasil di reset

**Status:** PASS
