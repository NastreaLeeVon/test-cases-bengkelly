# TC-10: Barang/Sparepart - Tambah, Edit, Hapus

## Deskripsi
Test case manual untuk memvalidasi bahwa Admin dapat menambahkan, mengedit, dan menghapus data barang/sparepart. (Sesuai referensi TMA_0010).

## Pre-conditions
- Aplikasi dapat diakses dengan normal di staging.
- Admin sudah berhasil login.
## Skenario: Admin ingin menambahkan, mengedit, dan menghapus barang/sparepart
Langkah-langkah:
1. Admin membuka halaman login.
2. Admin berhasil login.
3. Admin menavigasi ke menu Master Data > Barang/Sparepart.
4. Lakukan aksi Tambah data baru.
5. Lakukan aksi Edit pada data yang baru ditambahkan.
6. Lakukan aksi Hapus pada data tersebut.

Expected Result:
- Bisa menambahkan barang/sparepart baru.
- Bisa mengedit barang/sparepart yang ditambahkan.
- Bisa menghapus barang/sparepart.
