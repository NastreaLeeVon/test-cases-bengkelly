# TC-16: Booking - Admin melakukan validasi field wajib

## Deskripsi
Admin melakukan validasi field wajib. (Sesuai referensi SBA_002).

## Pre-conditions
- Admin berada pada form booking

## Skenario: Admin melakukan validasi field wajib

Langkah-langkah:

1. Buka form booking

Test Data:

- Field wajib dikosongkan

Expected Result:

- Sistem menolak penyimpanan dan menampilkan validasi pada field wajib.

Actual Result:

- Sistem menolak penyimpanan karena field wajib bekum diisi.

**Status:** PASS
