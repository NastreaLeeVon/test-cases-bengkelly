# TC-09: Dashboard - Akses Cepat Aktivitas Terkini

## Deskripsi
Test case manual untuk memvalidasi bahwa Admin memiliki akses cepat ke fitur yang baru dipakai di dashboard. (Sesuai referensi TMA_0009).

## Pre-conditions
- Aplikasi dapat diakses dengan normal di staging.
- Admin sudah berhasil login.
## Skenario: Admin ingin akses cepat ke aktivitas terkini
Langkah-langkah:
1. Admin membuka halaman login.
2. Admin berhasil login.
3. Admin melihat bagian akses cepat di dashboard.
4. Klik salah satu card fitur yang baru dipakai.

Expected Result:
- Menampilkan 2 card untuk akses cepat ke fitur yang baru-baru ini dipakai.
- Bisa mengantarkan ke halaman fitur tersebut (saat diklik).
