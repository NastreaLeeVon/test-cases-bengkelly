# TC-47: Pembayaran - Admin mencetak nota/bukti pembayaran

## Deskripsi
Admin mencetak nota/bukti pembayaran. (Sesuai referensi SBA_033).

## Pre-conditions
- Pembayaran sudah berhasil dan bukti pembayaran tersedia.

## Skenario: Admin mencetak nota/bukti pembayaran

Langkah-langkah:

1. Buka bukti pembayaran
2. Klik print/download
2. periksa

Test Data:

- Bukti pembayaran tersedia.

Expected Result:

- Bukti pembayaran berhasil dibuka untuk proses cetak.

Actual Result:

- Bukti pembayaran berhasil di print dan di download

**Status:** PASS
