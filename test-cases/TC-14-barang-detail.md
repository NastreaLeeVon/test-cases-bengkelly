# TC-14: Barang/Sparepart - Lihat Detail

## Deskripsi
Test case manual untuk memvalidasi bahwa Admin dapat melihat detail dari barang/sparepart. (Sesuai referensi TMA_0014).

## Pre-conditions
- Aplikasi dapat diakses dengan normal di staging.
- Admin sudah berhasil login.
- Terdapat minimal satu data barang/sparepart di dalam sistem.
## Skenario: Admin ingin melihat detail dari barang/sparepart yang sudah ditambahkan
Langkah-langkah:
1. Admin membuka halaman login.
2. Admin berhasil login.
3. Admin menavigasi ke menu Master Data > Barang/Sparepart.
4. Klik tombol Detail (biasanya icon mata) atau baris data pada salah satu barang.

Expected Result:
- Menampilkan detail dari barang/sparepart yang ditambahkan dengan informaåsi yang lengkap.
