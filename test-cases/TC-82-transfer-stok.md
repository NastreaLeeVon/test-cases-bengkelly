# TC-82: Admin ingin membuat transfer stok baru

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin membuat transfer stok baru.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.

## Skenario: Admin ingin membuat transfer stok baru

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password
4. Memilih halaman stok menu dan pembelian di sidebar
5. Memilih sub-menu Transfer Stok

Expected Result:

- Menampilkan form informasi transfer:
- Dari gudang -> gudang
- Tanggal transfer
- Estimasi tiba
- Alasan transfer
- Catatan
- Barang yang ditransfer
- Ringkasan
- Button simpan
- Bisa menyimpan transfer stok yang dilakukan ke gudang tujuan
