# TC-08: Dashboard - Ringkasan Penjualan Hari Ini

## Deskripsi
Test case manual untuk memvalidasi bahwa Admin dapat melihat data ringkasan cepat penjualan hari ini di dashboard. (Sesuai referensi TMA_0008).

## Pre-conditions
- Aplikasi dapat diakses dengan normal di staging.
- Admin sudah berhasil login.
## Skenario: Admin ingin melihat data ringkasan cepat penjualan hari ini
Langkah-langkah:
1. Admin membuka halaman login.
2. Admin berhasil login.
3. Admin melihat bagian ringkasan di atas dashboard.

Expected Result:
- Menampilkan data ringkas booking hari ini.
- Menampilkan data ringkas unit yang dikerjakan hari ini.
- Menampilkan data ringkas PKB yang aktif.
- Menampilkan data ringkas omset yang diperoleh hari ini.
