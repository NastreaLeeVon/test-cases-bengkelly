# TC-32: PKB - Admin mengambil sparepart dari gudang untuk PKB

## Deskripsi
Admin mengambil sparepart dari gudang untuk PKB. (Sesuai referensi SBA_018).

## Pre-conditions
- PKB memiliki kebutuhan sparepart dan stok tersedia di gudang.

## Skenario: Admin mengambil sparepart dari gudang untuk PKB

Langkah-langkah:

1. Buka PKB dan ambil part dari gudang
2. Pilih sparepart
3. Isi quantity
4. Klik ambil part dan periksa data part

Test Data:

- Sparepart tersedia di gudang.

Expected Result:

- Sparepart berhasil diambil sesuai quantity dan stok gudang diperbarui sesuai transaksi.

Actual Result:

- Part berhasil diambil dari gudang.

**Status:** PASS
