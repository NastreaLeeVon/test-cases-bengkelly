# TC-35: PKB - Admin melakukan reset pada form PKB

## Deskripsi
Admin melakukan reset pada form PKB. (Sesuai referensi SBA_021).

## Pre-conditions
- Admin berada pada form buat PKB baru dan sudah mengisi data.

## Skenario: Admin melakukan reset pada form PKB

Langkah-langkah:

1. Isi beberapa data pada from PKB
2. Klik button reset
3. Periksa form

Test Data:

- Data PKB Yang sudah diisi.

Expected Result:

- Seluruh isi form ke kondisi awal/kosong.

Actual Result:

- Form PKB berhasil di-reset ke kondisi awal

**Status:** PASS
