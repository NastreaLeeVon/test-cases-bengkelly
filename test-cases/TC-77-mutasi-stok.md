# TC-77: Admin ingin melihat ringkasan data mutasi stok

## Deskripsi

Test case manual untuk memvalidasi bahwa Admin ingin melihat ringkasan data mutasi stok.

## Pre-conditions

- Admin sudah berhasil login

## Test Data

- Tidak ada data.

Langkah-langkah:

1. Admin membuka halaman dev.bengkelly.co.id
2. Input username          3.Input password

Actual Result:
