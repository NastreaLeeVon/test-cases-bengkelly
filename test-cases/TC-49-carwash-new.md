# TC-49: Car Wash - Admin membuat dan memproses order car wash sampai selesai

## Deskripsi
Admin membuat dan memproses order car wash sampai selesai. (Sesuai referensi SBA_035).

## Pre-conditions
- Admin berada di menu car wash

## Skenario: Admin membuat dan memproses order car wash sampai selesai

Langkah-langkah:

1. Buka menu car wash
2. Klik order baru
3. Isi customer, kendaraan, dan paket
4. Klik buat order

Test Data:

- Data customer dan kendaraan
- paket cuci valid.

Expected Result:

- Order berhasil dibuat, status berubah menjadi dikerjakan saat mulai cuci, lalu menjadi selesai.

Actual Result:

- Order car wash berhasil dibuat, diproses, dan status menjadi selesai.

**Status:** PASS
