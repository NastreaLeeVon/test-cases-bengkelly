# TC-38: PKB - Admin mencetak detail PKB

## Deskripsi
Admin mencetak detail PKB. (Sesuai referensi SBA_024).

## Pre-conditions
- PKB sudah berhasil dibuat dan tersedia pada detail PKB>

## Skenario: Admin mencetak detail PKB

Langkah-langkah:

1. Buka detail PKB
2. Klik tombol cetak/print PKB
3. Periksa

Test Data:

- Data PKB tersedia.

Expected Result:

- Dokumen/detail PKB berhasil dibuka untuk proses cetak.

Actual Result:

- Detail PKB berhasil di print

**Status:** PASS
