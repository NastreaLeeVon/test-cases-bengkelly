# TC-51: Display Ruang Tunggu - Admin menampilkan informasi pada display ruang tunggu

## Deskripsi
Admin menampilkan informasi pada display ruang tunggu. (Sesuai referensi SBA_037).

## Pre-conditions
- Admin berada pada menu display ruang tunggu.

## Skenario: Admin menampilkan informasi pada display ruang tunggu

Langkah-langkah:

1. Buka menu display ruang tunggu
2. Periksa informasi yang ditampilkan
3. Pastikan tampilan dapat digunakan

Test Data:

- Data display

Expected Result:

- Halaman display ruang tunggu dapat dibuka dan informasi tampil dengan baik.

Actual Result:

- Display ruang tunggu berhasil diakses dan informasi tampil.

**Status:** PASS
